Optional source retrieval
  licenses/fetch-sources.py is provided for inspecting and downloading the
  pinned source references. Installation never runs it. It does not compile
  software, change the installed runtime, or collect browser/user data.
  Python 3.9+ is required; Git/SVN are also needed for those source entries.

  List the references without downloading:
    python fetch-sources.py --group core
  Explicitly fetch the main project sources into a new directory:
    python fetch-sources.py --group core --fetch --output source-downloads
  Fetch the indexed dependency sources as well (can be large):
    python fetch-sources.py --group ffmpeg-deps --group deno-deps --fetch --output dependency-sources

  The downloader checks published hashes where supplied and records hashes for
  downloaded archives. It preserves Git submodules recursively. Build systems
  may fetch further dependencies described by the upstream recipes; inspect
  those recipes before describing an assembled archive as complete source.
  Keep any source companion archive with the installer when sharing it.
