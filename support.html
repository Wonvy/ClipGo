ClipGo Support / 使用帮助

ClipGo saves supported videos with a separate Windows desktop helper. Only download content you are authorized to save. Protected videos are not supported.

ClipGo 需要安装 Windows 本地助手。请仅下载你有权保存的内容，不支持受保护视频。

Install / 安装

Download the Chrome + Edge helper / 下载双商店助手. Install it, restart the browser, and check that ClipGo shows the helper as ready.
