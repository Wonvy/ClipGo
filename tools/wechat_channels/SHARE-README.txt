ClipGo 视频号 1.0.0 使用说明

安装与打开
适用于 Windows 10 / 11 64 位。运行安装程序后，从开始菜单打开“ClipGo 视频号”。无需安装 Python。
需要 Microsoft .NET Framework 4.8 和 Microsoft Edge WebView2。多数电脑已经具备；安装程序会检查，缺少 WebView2 时会提示从微软下载安装，届时需要联网。
本安装包尚未签名，Windows 可能显示“未知发布者”；请核对文件确实来自你信任的分享者。

保存视频
1. 打开并登录微信，在视频号中播放想保存的视频几秒。微信主界面和独立播放窗口都支持，无需切换来源。
2. 打开 ClipGo，等待自动读取。根据封面、标题、作者和时长找到视频，点击“下载”。微信可能提前加载其他视频，请确认卡片内容。
3. 默认保存到“下载”文件夹中的“ClipGo视频号”。右上角设置可以更改保存位置，或打开保存文件夹。

播放与整理
点击卡片或标题可在 ClipGo 内播放。首次播放需要准备视频，请等待进度完成。播放时按空格暂停或继续，按 Esc 关闭播放器。
自动同步会持续添加新视频、更新已读信息；可暂停同步或手动刷新。已有列表会保留，可按标题或作者搜索。
卡片上的四个图标依次表示喜欢、分享、点赞、评论。未读到的数值显示“—”，悬停可查看完整数值；微信缓存数据可能稍有延迟。
删除卡片或“清空”仅移除列表记录，不会删除已下载的文件。已移除记录在本次运行中不会因刷新重新出现，正在进行的下载会继续。

遇到问题
尚未看到视频：确认微信已登录，重新播放目标视频，等待自动同步或点击“刷新”。
下载失败：地址可能已过期，请在微信重新播放该视频后刷新。缺少必要信息的条目暂时无法下载。
已在 Windows 微信 4.1.15.56 验证。微信升级、不同视频格式或内容状态可能影响识别；目前不支持直播录制或 DRM 内容。
本版本只读识别微信已经加载的视频，不包含实验网络监听功能。请只保存有权下载的内容。

升级与卸载
升级前先关闭 ClipGo，再运行新版安装程序。可在 Windows“设置 → 应用”中卸载；卸载会保留已下载的视频。
分享时发送完整安装程序即可，无需发送自己的下载文件、微信数据或应用缓存。第三方组件的声明及原始许可随软件安装。
