optional regular HTTPS page proxy. The accompanying
licenses directory retains original upstream license and notice texts.
The summaries below do not replace those texts. Component versions are
pinned by tools/wechat_channels/requirements-release.txt and the release
build manifest.

The release excludes WinDivert binaries/drivers, mitmproxy's local process
redirector packages, the legacy Tk interface, terminal console and browser
automation tools. The optional page proxy uses ordinary HTTP(S) connections.
Application source and build instructions are provided in the companion
source archive. Upstream links identify the original projects; they are
not substitutes for the original license texts included with this release.
